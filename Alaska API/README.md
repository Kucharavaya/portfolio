### <a id="title1"> Краткое введение </a>
***Docker Image*** доступен для скачивания в репозитории: https://hub.docker.com/r/azshoo/alaska.

При запуске контейнера стартует приложение, доступное внутри контейнера по адресу http://localhost:8080.
Документацию для API можно получить внутри контейнера (отправив ***GET*** запрос на эндпоинт ***/info***)

Alaska API — это ***CRUD-сервис*** для управления медведями (*bears*) в Аляске.
Сервис предоставляет набор ***REST-эндпоинтов***, позволяющих создавать, читать, обновлять и удалять записи о медведях. 

Каждый медведь описывается JSON-объектом со следующими полями:

```
json
{
  "bear_id": 1,
  "bear_type": "BLACK",
  "bear_name": "MIKHAIL",
  "bear_age": 17.5
}
```

Допустимые значения `bear_type`: `POLAR`, `BROWN`, `BLACK`, `GUMMY`.

### <a id="title2"> Для поля `bear_age` были определены классы эквивалентности и граничные значения</a> 
| Позитивные классы      | Граничные значения                       | 
|-|-|					
| 0 - 100                | -0.01, 0, 0.01, 99.99, 100, 100.01 |					
| **Негативные классы**      |                      |
|-|-|					
| от - :infinity:  до -0.01| для - :infinity: нет, -0.01               |
| 17.000000005           | 17.000000005                             |
| от 100.01 до + :infinity: | 100.01, для + :infinity: нет             |
| строковое значение     | нельзя определить                        |
| спецсимволы	         | нельзя определить                        |

### <a id="title3"> Что было выполнено</a>
В рамках тестирования Alaska API реализовано ***полное покрытие CRUD-операций***:

|Категория|	Количество тестов|	Описание|
|--|--|--|
|POST /bear|	46 тест-кейсов	|Создание медведя с валидацией всех полей (bear_type, bear_name, bear_age), проверка дублирования, негативные сценарии|
|GET /bear|	2 тест-кейса	|Получение всех записей (в т.ч. из пустой БД)|
|GET /bear/:id|	2 тест-кейса	|Получение существующего и несуществующего медведя|
|PUT /bear/:id|	8 тест-кейсов	|Обновление всех полей и отдельных полей, негативные сценарии (400/404)|
|DELETE /bear/:id|	3 тест-кейса	|Удаление существующего, повторное удаление, удаление несуществующего|
|DELETE /bear|	2 тест-кейса	|Удаление всех записей и удаление при пустой БД|
|GET /info|	1 тест-кейс	|Проверка отображения документации API|

***Итого: ~64 тест-кейса***, сгруппированных по методам и типам сценариев (200, 400, 404).
