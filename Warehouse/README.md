Пет-проект: Модуль складского учёта и движения товарных накладных.
Основан на опыте работы с товарными накладными, складом и инвентаризациями.

## 📌 Контекст / Зачем этот проект

Столовая ведёт учёт продуктов вручную: кладовщик заполняет книгу складского учёта, ежедневно формирует товарный отчёт для бухгалтерии, ведёт журнал скоропортящихся продуктов. Это трудоёмко, подвержено ошибкам человеческого фактора и не даёт оперативной картины остатков. Подробнее — [Контекст/context.md](Контекст/context.md).
