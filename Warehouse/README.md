# Пет-проект:  Warehouse

Модуль складского учёта и движения товарных накладных.
Основан на опыте работы с товарными накладными, складом и инвентаризациями.

**Автор:** [КУЧЕРЯВАЯ АНАСТАСИЯ](https://github.com/Kucharavaya)  
**Статус:** в разработке · **Целевая роль:** Junior QA / Тестировщик ПО · Бизнес-аналитик

## 📌 Контекст / Зачем этот проект

Столовая ведёт учёт продуктов вручную: кладовщик заполняет книгу складского учёта, ежедневно формирует товарный отчёт для бухгалтерии, ведёт журнал скоропортящихся продуктов. Это трудоёмко, подвержено ошибкам человеческого фактора и не даёт оперативной картины остатков. Подробнее — [context.md](context.md).
